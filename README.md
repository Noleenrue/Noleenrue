## 🚀 Featured Project

### 🏥 Adaptive Hospital Intelligence Platform

An end-to-end machine learning research prototype that estimates **30-day hospital readmission risk at discharge**.

**Highlights**
- XGBoost-based readmission risk prediction
- Calibrated prediction probabilities
- SHAP explanations for individual predictions
- FastAPI backend and Streamlit dashboard
- PostgreSQL prediction history and analytics
- Cloud deployment and automated testing

**Tech stack:** Python · XGBoost · Scikit-learn · FastAPI · Streamlit · PostgreSQL · SHAP

[🌐 Live Demo](https://adaptive-hospitalinteligence-platform-cqx99uqjrwebu2j9j7bpys.streamlit.app/) | [💻 Source Code](https://github.com/Noleenrue/Adaptive-Hospital_Inteligence-Platform) | [📖 API Docs](https://adaptive-hospital-api.onrender.com/docs)

*Research prototype only — not clinically validated or intended for patient-care decisions.*
